# Three-minute hackathon pitch

**0:00–0:25 — The problem**
“Most dashboards start with configuration. We start with a question. Glance turns that question into a useful view of your data.”

**0:25–1:00 — Generate**
Open the app and click **Revenue & customers**. Point to the revenue chart and customer table. Explain that the model chooses from vetted widgets, while ordinary code calculates every displayed number. If using the no-key setup, explicitly say this run uses the local fallback; do not imply the model was called.

**1:00–1:30 — Refine**
Click **Accounts at risk**, open Filters, and choose the At risk customer status. Show the table and the matching count/average. Clear filters afterwards.

**1:30–2:10 — Bring your data**
Download the JSON example, change a customer's amount, and import it. Explain that imports are validated and stay in the browser; only the prompt is sent for model selection. The UI identifies the imported dataset.

**2:10–2:35 — Make it yours**
Add a view, change the layout, save the dashboard with a name, and reload. Restore it from the sidebar. Export CSV using the active filters.

**2:35–3:00 — Reliability and close**
Show Billing & conversion on demo data: the invoice is $3,396. Explain that if the AI service times out, the dashboard stays useful. Close with: “A question, a clear view, and the data behind every number.”

Before recording, use fictional demo data only. Keep a second browser tab open with the app loaded. The optional automated demo recording captures the core workflow without narration.
