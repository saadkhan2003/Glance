# Three-minute hackathon pitch

**0:00–0:25 — The problem**
“Most dashboards start with configuration. We start with a question. Glance turns that question into a useful view of your data.”

**0:25–1:00 — Generate**
Open the app, click **Load sample data**, choose **Show revenue growth and top customers**, and click **Generate dashboard**. Point to the revenue chart and customer table. Explain that Jev chooses from vetted widgets, while ordinary code calculates every displayed number. If using the no-key setup, explicitly say this run uses the local fallback; do not imply the model was called.

**1:00–1:30 — Refine**
Choose **Which customers are at risk?**, click **Generate dashboard**, and choose the At risk customer status in the live filters. Show the table and the matching count/average. Clear filters afterwards.

**1:30–2:10 — Bring your data**
Import a small CSV or JSON example. Explain that imported records and saved views live in this browser, while Excel and SQLite files briefly reach the server for conversion. Only the question and source label reach Jev, not uploaded rows.

**2:10–2:35 — Make it yours**
Add a view, change the layout, save the dashboard with a name, and reload. Restore it from the sidebar. Export CSV using the active filters.

**2:35–3:00 — Reliability and close**
Show the **Give feedback** and **Request a pilot** buttons. Explain that if Jev is unavailable, the local dashboard still works. Close with: “A question, a clear view, and the data behind every number.”

Before recording, use fictional demo data only. Keep a second browser tab open with the app loaded. The optional automated demo recording captures the core workflow without narration.
